# \# Sistema OficinaPro

# 

# \*\*Status do projeto:\*\* Em desenvolvimento

# 

# \## Tecnologias Aplicadas

# \* Java (Swing/JFrame para interface gráfica)

# \* Banco de Dados MySQL (via MySQL Workbench)

# \* JDBC (Java Database Connectivity)

# 

# \## Time de Desenvolvedores

# \* \[Angelo Murgia]

# 

# \## Objetivo do Software

# O Sistema OficinaPro tem como objetivo facilitar a gestão de uma oficina mecânica, permitindo o registro rápido e prático das ordens de serviço, organizando o cadastro de manutenções vinculadas às placas dos veículos diretamente em um banco de dados.

# 

# \## Funcionalidades do Sistema (Requisitos)

# \* Navegação intuitiva entre telas (Menu Principal e Tela de Ordem de Serviço).

# \* Formulário para inserção de dados da Ordem de Serviço (Placa do Veículo e Serviço Realizado).

# \* Conexão com banco de dados relacional (MySQL).

# \* Persistência de dados: Gravação de novas ordens de serviço diretamente no banco de dados.
